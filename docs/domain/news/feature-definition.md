# 실시간 뉴스 정보 페이지 기능 정의서

## 1. 기능 개요

사용자가 현재 발생 중인 재난·사고 뉴스를 빠르게 확인하고, 현재 위치 또는 선택 지역과 관련된 위험 정보를 파악할 수 있도록 제공하는 페이지이다.

SafeCheck는 공공 재난 API에서 제공하는 재난·재해 정보와 뉴스 기반 사건사고 정보를 함께 활용하여 사용자에게 최신 안전 정보를 제공한다.

---

## 2. 문제 정의

재난·사고 정보는 여러 사이트와 서비스에 흩어져 있다.

사용자는 현재 발생한 사고 정보를 확인하기 위해 직접 포털에 접속하고, 뉴스 탭에 들어가고, 사건사고 또는 재난 관련 키워드를 검색해야 한다.

하지만 이 방식에는 다음 문제가 있다.

- 사용자가 직접 검색해야 한다.
- 지역과 무관한 뉴스가 많이 노출된다.
- 같은 사건을 여러 언론사가 중복 보도한다.
- 뉴스 속보는 빠르지만 신뢰도와 중복 문제가 있다.
- 일반 재난 API에서는 칼부림, 흉기난동, 가스 누출, 폭발, 붕괴, 대형 교통사고 같은 사건사고성 정보가 충분히 제공되지 않는다.

따라서 SafeCheck는 사용자가 직접 검색하지 않아도 현재 위치 또는 선택 지역 기준으로 관련 사건사고 뉴스를 확인할 수 있는 기능을 제공한다.

---

## 3. 사용자 대상

- 일반 사용자
- 현재 발생 중인 사건, 사고, 재난, 재해 정보를 확인하려는 사용자
- 내 위치 주변의 위험 정보를 빠르게 확인하려는 사용자
- 특정 지역의 안전 상황을 확인하려는 사용자

---

## 4. 사용자 시나리오

1. 사용자가 실시간 뉴스 정보 페이지에 진입한다.
2. SafeCheck는 현재 위치 또는 사용자가 선택한 지역을 기준으로 뉴스를 조회한다.
3. 사용자는 재난 유형, 지역, 위험도, 최신순 조건으로 필터링한다.
4. 위험도가 높은 뉴스는 뱃지 또는 강조 UI로 표시된다.
5. 사용자는 뉴스 상세 정보를 확인하고 원문 링크로 이동할 수 있다.

---

## 5. 주요 기능 정의

### 5-1. 실시간 뉴스 목록 조회

사용자는 실시간으로 수집된 사건사고 뉴스를 목록 형태로 확인할 수 있다.

조회 조건은 다음과 같다.

- 최신순 조회
- 지역별 조회
- 재난 유형별 조회
- 위험도별 조회
- 키워드 기반 검색

---

### 5-2. 뉴스 상세 조회

뉴스 상세 화면에서는 다음 정보를 제공한다.

- 제목
- 요약
- 원문 링크
- 출처
- 언론사
- 발생 지역
- 발행 시간
- 수집 시간
- 위험도
- 관련 키워드
- 사건 유형

뉴스 전문과 이미지는 SafeCheck 내부에 저장하지 않고, 원문 기사 링크를 통해 확인하도록 한다.

---

### 5-3. 필터 및 검색

사용자는 다음 조건으로 뉴스를 필터링할 수 있다.

- 지역 필터
- 재난 유형 필터
- 위험도 필터
- 키워드 검색
- 최신순 정렬
- 위험도순 정렬

---

### 5-4. 위험도 표시

뉴스의 위험도는 다음 4단계로 표시한다.

| 위험도   | 설명      |
| -------- | --------- |
| LOW      | 낮음      |
| MEDIUM   | 보통      |
| HIGH     | 높음      |
| CRITICAL | 매우 높음 |

위험도는 사건 유형, 인명 피해, 규모, 공공 영향, 사용자 위치와의 연관성을 기준으로 산정한다.

초기 MVP에서는 룰 기반 점수제를 사용하고, 향후 데이터가 충분히 쌓이면 AI 기반 분석 또는 임베딩 기반 유사도 분석을 추가할 수 있다.

---

### 5-5. 중복 뉴스 처리

같은 사건을 여러 언론사가 보도할 수 있으므로 중복 처리가 필요하다.

중복 처리는 두 단계로 나눈다.

### 1단계. 기사 단위 중복 제거

같은 네이버 기사 URL이 여러 번 저장되지 않도록 기사 고유키를 기준으로 중복 제거한다.

예시:

```
NAVER:{pressCode}:{articleId}
```

### 2단계. 사건 단위 그룹핑

서로 다른 언론사가 같은 사건을 보도한 경우 하나의 사건으로 묶을 수 있다.

초기 MVP에서는 기사 단위 중복 제거를 우선 적용하고, 사건 단위 그룹핑은 고도화 단계에서 적용한다.

---

## 6. 데이터 수집 방식 요약

SafeCheck의 실시간 뉴스 정보 페이지는 다음 데이터 수집 방식을 사용한다.

| 수집원                      | 역할                                     |
| --------------------------- | ---------------------------------------- |
| 연합뉴스 재난·재해 API      | 공신력 있는 재난·재해 데이터 수집        |
| 네이버 사건사고 뉴스 수집기 | 공공 API에서 부족한 사건사고성 정보 보완 |

연합뉴스 API는 재난·재해 유형이 명확한 데이터를 수집하는 데 적합하다.

반면 칼부림, 흉기난동, 가스 누출, 폭발, 붕괴, 대형 교통사고 같은 사건사고성 정보는 일반 재난 API만으로 충분히 수집하기 어렵다.

따라서 SafeCheck는 네이버 뉴스의 사회 > 사건사고 섹션을 보조 데이터 수집원으로 활용한다.

네이버 사건사고 뉴스는 브라우저 자동화 방식이 아니라, 사건사고 섹션의 더보기 요청 구조를 분석하여 cursor 기반 증분 수집 방식으로 처리한다.

수집 방식, 중복 제거, 키워드 필터링, 위험도 산정, 스케줄러 정책은 별도 문서인 “네이버 사건사고 뉴스 수집 설계서”에서 정의한다.

## 7. 기능 범위

### MVP 범위

- 실시간 뉴스 목록 조회
- 뉴스 상세 조회
- 지역 필터
- 사건 유형 필터
- 위험도 필터
- 키워드 검색
- 네이버 사건사고 뉴스 수집
- 기사 URL 기반 중복 제거
- 포함/제외 키워드 기반 필터링
- 룰 기반 위험도 산정

### 고도화 범위

- 같은 사건을 여러 기사에서 묶는 incident 그룹핑
- AI 기반 요약
- AI 기반 위험도 분석
- 사용자 위치 기반 거리 계산
- 실시간 알림
- 사용자 관심 지역 설정
- 사건 발생 추이 통계
